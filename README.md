# PMRD-Net

Official implementation of **PMRD-Net: A Physics-Prior-Guided Multi-Response Dynamic Network for Real-World Non-Homogeneous Image Dehazing**.

## Overview

PMRD-Net is designed for real-world non-homogeneous image dehazing.

The framework mainly consists of:

- Pixel-Wise Prior Calibration Module (PPCM)
- Multi-Response Dynamic Routing (MRDR)
- Transmission-Gated Multiscale Reconstruction (TGMR)
- Physics-Guided Dynamic Structure Preservation (PG-DSP)
